Features

Everything you need

Powerful search, Timestamp Links, multiple export formats, themes, and Pro tools — free core features, with Pro unlocking even more.

🔍
Instant full-text search

Search the entire transcript as you type. Case-sensitive mode, whole-word preference, history, and undo/redo of search states.

⏱️
Timestamp jump

Click any result or transcript line to jump to that precise moment. Prev/Next through matches; Following mode keeps the current line in view.

📋
Timestamp Link collection

Colour-coded batches per search. Tick, delete, expand/collapse, and export only the moments you need. Append mode and manual add on Pro.

📤
Multiple export formats

TXT and clipboard free. SRT, CSV, JSON & Markdown with Pro. Synced or original timestamps. Metadata headers included.

📺
Teleprompter Pro

Floating panel that scrolls with the video. Font, cascade, background, active-line highlight, view-mode profiles (N/C/F), anchor to video.

🎨
Multiple colour themes

Light, dark, and specialised colourways. Default Deep Ocean. Opacity control so the video can show through.

🗺️
Minimap Pro

Coloured dots for every match along the transcript. Click to jump. Show/hide from the video-info row.

🔒
URL lock & language picker Pro

Freeze URL and transcript while browsing. Long-press Load Transcript for every caption language and track YouTube offers.

🔒
Fully private

No account required. No data sent to us. Transcripts come straight from YouTube; preferences stay on your device.
